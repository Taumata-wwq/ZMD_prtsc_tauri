# 终末地俯瞰模式截图工具

基于 Tauri 2 + Vue 3 + Rust 的终末地游戏俯瞰模式自动截图工具。通过蛇形遍历游戏画面并自动拼接，生成高分辨率基建及大地图。

## 功能

- **自动截图**：蛇形遍历游戏画面，通过中键拖拽移动相机，自动拼接生成完整基建
- **裁剪导出**：主界面直接裁剪，支持 JPG / PNG 格式导出
- **历史记录**：会话管理，查看截图详情和输出路径
- **数据管理**：区域配置管理，支持通过目标尺寸（target_w / target_h）反推截图参数
- **全局热键**：F3 开始 / 停止截图
- **中英文切换**：设置界面支持语言切换
- **窗口状态持久化**：位置、大小、置顶状态自动保存和恢复

## 使用方法

### 准备工作

1. 将游戏分辨率调整为 16:9（最小1280*720）
2. 在游戏中按 X 键进入批量选择模式
3. 滚轮向上滚动，缩放至紧贴地面的高度，并移动画面到目标区域左上角
4. 截图过程中请勿移动鼠标

### 截图流程

1. 在左侧「区域」下拉框中选择目标区域（如 武陵-武陵城）
2. 在「滚动次数」下拉框中选择缩放级别（0次为最近地面，8次为可选的最远视野）
3. 点击「开始截图」或按 F3 键启动
4. 等待截图完成后，在右侧预览区拖拽可选择裁剪范围
5. 点击「导出裁剪」或「导出原图」保存图像

### 数据管理

在「数据管理」页面可以查看和修改各区域的配置参数：

- 点击区域行进入编辑模式，修改 target_w / target_h 后自动推导行列数和拖拽距离
- 点击其他区域或空白处自动保存并收起编辑
- 大地图和自定义区域的网格参数可独立编辑

### 导出文件名

默认格式为 `区域_时间戳_滚动次数`，可在设置中自定义。支持占位符：

- `{region}` — 区域名称
- `{timestamp}` — 时间戳
- `{scrollMode}` — 滚动次数

## 环境要求

- Windows 10 / 11
- Node.js 18+
- Rust 1.75+（stable）
- 终末地游戏客户端（需以管理员权限运行）

## 构建

```bash
# 安装前端依赖
npm install

# 开发模式
npm run tauri:dev

# 类型检查
npm run typecheck

# 生产构建
npm run tauri:build
```

## 技术栈

| 层     | 技术                                     |
| ------ | ---------------------------------------- |
| 前端   | Vue 3 + TypeScript + Pinia + Vite        |
| 后端   | Rust + Tauri 2                           |
| 数据库 | SQLite（rusqlite）                       |
| 图像   | image crate + rayon 并行拼接             |
| 输入   | Windows SendInput API（中键拖拽 + 滚轮） |
| 热键   | tauri-plugin-global-shortcut             |

## 注意事项

- 应用需以管理员权限运行（通过 `ShellExecuteExW("runas")` 运行时提权），与游戏权限级别一致
- 仅支持 Windows 平台
- 导出图像使用文件路径零拷贝传输，避免大数据序列化开销
- 截图过程中主窗口默认自动最小化，完成后恢复
